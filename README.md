# Код дня — статический концепт сайта

Это одностраничный статический прототип сайта для русскоязычной аудитории:

- ежедневный ритуал,
- рейтинг знаков,
- личное число дня,
- формула дня,
- lucky-элементы,
- блоки “что делать / чего избегать”,
- retention-петля утро → день → вечер,
- структура MVP, roadmap, позиционирование и монетизация.

## Запуск локально

Откройте `index.html` в браузере

или поднимите простой сервер:

```bash
python3 -m http.server 8000
```

После этого откройте <http://localhost:8000>.
